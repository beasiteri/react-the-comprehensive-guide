# React Container Components

A practical React example demonstrating the container component pattern.

This example is part of the **[React The Comprehensive Guide](https://github.com/beasiteri/react-the-comprehensive-guide)** project, which provides an overview of the topics and links to the individual implementations.

## Example

The project demonstrates how to separate data fetching and state management from presentation using container and presentational components.

It covers:

- Separating data and state management from presentation
- Managing loading and error states in a container component
- Passing data and state to presentational components
- Keeping presentational components focused on rendering UI
- Using Mock Service Worker (MSW) to mock API responses

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Material UI
- Axios
- Mock Service Worker (MSW)

## Running Locally

Clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd <repository-name>
npm install
npm run dev
```

The application starts using Vite with MSW providing the mocked API responses.
