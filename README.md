# React Higher Order Components

A practical React example demonstrating the higher order component pattern.

This example is part of the **[React The Comprehensive Guide](https://github.com/beasiteri/react-the-comprehensive-guide)** project, which provides an overview of the topics and links to the individual implementations.

## Example

The project demonstrates how higher order components can be used to reuse component logic and enhance existing components.

It covers:

- Creating higher order components
- Reusing component logic across multiple components
- Passing props through higher order components
- Enhancing components with additional behavior
- Separating reusable logic from presentation

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Material UI
- Axios
- Mock Service Worker (MSW)

## Running Locally

Clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd <repository-name>
npm install
npm run dev
```

The application starts using Vite with MSW providing the mocked API responses.
